# OCTAGON CLASH

PC + mobile custom-fighter fighting game.

## Controls
PC: WASD / Arrow keys to move; J jab; K cross; L kick; I block; O takedown; P heavy.

Mobile: use the on-screen controls.

## Custom fighter images
Put these files in `octagon-clash/assets/`:
- keithlocks.jpg
- makotojay.jpg
- fargoforce.jpg
- scapegoatie.jpg

Then open `index.html` (or configure GitHub Pages to serve this folder).

This prototype uses virtual gameplay only and has no real-money wagering features.
